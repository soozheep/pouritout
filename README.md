# Pour It Out — Sonic Remedy

**Audiosensory Resonance** by Soozhee · Produced by Caelverum Music

Live at: https://pouritout.vercel.app

## Assets required

Place the following in the `assets/` folder (already prepared in local workspace):

- `cover.jpg`
- `pour-it-out.mp3`
- `lyrics/pio-01.jpg` … `pio-10.jpg`
- `cards/card-01.jpg` … `card-04.jpg`

Connect this repo to Vercel and set the domain to `pouritout.vercel.app`.

Streaming links (Spotify / Apple Music / Amazon Music) are currently placeholders (`#`). Update them in `index.html` once the track is live on the platforms.
